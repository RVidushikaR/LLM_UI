# LLM Blocks Playground

An interactive visual playground to build and explore LLM and ML pipelines using draggable 2D/3D blocks.  
Supports models like BERT, CLIP, ViT, GPT, and LLaMA with real-time visualization of embeddings, attention maps, and model outputs.

---

## 🚀 Features

- Drag-and-drop LLM / ML blocks
- 3D visualization using Three.js
- Attention heatmaps and embedding visualizations
- Support for vision and language models (ViT, CLIP, BERT, etc.)
- Attack simulation (Backdoor, Patch attacks)
- Interactive execution pipeline with connections between blocks
